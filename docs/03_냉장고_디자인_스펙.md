작성: 정하늘 (프로덕트 디자이너)

## 이 문서는 v2입니다 — 최신 스펙 = 이 문서 전체

`src/`에는 현재 v1(카드 그리드 기반 스큐어모픽)이 구현되어 있습니다. 사용자 피드백에 따라 v2로 개정하며, **프론트엔드 구현은 이 문서(v2) 기준으로 다시 진행**해야 합니다. v1 문서 내용은 이 파일에 남아있지 않고 전체가 v2로 대체되었습니다.

### v1 → v2 변경 요약

| 항목 | v1 | v2 | 이유 |
|---|---|---|---|
| 재료 표현 패러다임 | `grid-cols-3` 균일 그리드 + `aspect-square` 카드(`rounded-2xl`) | **선반 위에 놓인 실물 용기 실루엣**(`IngredientVessel`), `flex-wrap` 자유 배치 | "재료 표현을 카드가 아닌 다른 방식으로" 피드백 — 카드 그리드 패러다임 자체를 탈피 |

| 래스터 에셋 | 미사용 | **미사용 유지** | 8장 원칙 불변 |

> 이번 개정에서 손대지 않은 부분(탭 구조, D-day 배지 색/회전, + 버튼, 레시피 추천 CTA, 반응형 브레이크포인트)은 v1 그대로이며 아래 본문에 다시 기술되어 있으니 "v1이 어딘가 남아있나" 헷갈릴 필요 없이 이 문서 하나만 보면 됩니다.

## 0. 디자인 컨셉

> 실물을 흉내내되, 정보는 실물보다 빨리 읽혀야 한다.

"냉장고 화면 = 카드 그리드"가 아니라 "**문을 연 냉장고 내부를 들여다보는 화면**"으로 재해석하는 v1의 방향은 유지하되, v2에서는 두 가지를 더 밀어붙입니다.

1. **선반 자체와 프레임의 물성**을 CSS만으로 더 사실적으로 표현합니다 — 유리 선반의 두께감(빛 받는 윗면 + 그림자 지는 아랫면), 도어의 고무 개스킷(문 안쪽 테두리를 따라 도는 이중 홈), 손잡이의 금속 광택(단일 그라데이션이 아니라 하이라이트 스트릭이 지나가는 원통형 반사), 냉동실의 성에(도트 패턴 + 미세한 스크래치 결), 냉장실의 내부 조명(문을 열면 위에서 쏟아지는 백색광 워시).
2. **재료는 더 이상 "카드"가 아니라 "선반 위에 놓인 용기"** 입니다. 모든 재료가 동일한 정사각형 틀에 담기지 않고, 재료의 실제 포장/보관 형태를 단순화한 실루엣(우유팩, 에그박스, 채소 묶음, 두부 박스, 냉동 파우치, 오일 보틀 등)으로 표현되며, 선반의 같은 바닥선 위에 실물처럼 나란히·비뚤빼뚤 놓입니다.

정보 위계는 v1과 동일하게 유지합니다: 재료명 > D-day > 카테고리. 용기 실루엣은 장식이지 정보 전달 수단이 아니므로, 이름과 D-day는 항상 실루엣 밖(아래/위)에 고정 위치·고정 크기 텍스트로 노출해 "실루엣을 못 알아봐도 정보는 즉시 읽히게" 합니다.

- 탭(전체/실온/냉장/냉동)은 냉장고 앞면의 **온도 다이얼/조작부** 은유 — v1과 동일, 변경 없음.
- 실온 재료는 **도어 포켓(문 안쪽 바구니, 우드톤)**, 냉장 재료는 **유리 선반 + 밝은 백색광**, 냉동 재료는 **성에 낀 유리 선반**으로 구분 — v1과 동일, 다만 v2에서는 유리 선반에 두께감을, 냉동 선반에 서리 스크래치 결을 추가.
- 유통기한 임박 표시는 냉장고 문에 붙이는 **자석 스티커(메모지)** 은유의 D-day 배지 — v1과 동일, 변경 없음.
- + 버튼은 도어 포켓에 붙은 **자석 버튼**, "레시피 추천받기" 버튼은 문에 붙은 **메뉴 쪽지(핀으로 고정된 메모)** — v1과 동일, 변경 없음.

## 3. 컴포넌트별 스타일 규칙

### 3-1. 냉장고 프레임 (`FridgeFrame`, 사실감 강화)

기존 구조·배경색·라운드는 유지하고 아래를 **추가**합니다.

- **문 개스킷**: 프레임 컨테이너에 이중 `inset` 박스섀도우를 추가해 도어 안쪽을 따라 도는 고무 실을 표현합니다. 예: `shadow-[0_22px_44px_-20px_rgba(15,15,25,0.32),inset_0_0_0_6px_rgba(255,255,255,0.55),inset_0_0_0_7px_rgba(20,20,30,0.08)]` (다크: 두 번째/세 번째 레이어를 `rgba(255,255,255,.06)`, `rgba(0,0,0,.35)`로 교체).
- **앰비언트 드롭섀도우**: 위 박스섀도우 첫 레이어(`0 22px 44px -20px ...`)로 프레임이 배경 위에 "놓여있는" 입체감을 줍니다. 기존 `shadow-[0_1px_0_...inset]`은 유지하되 병합.
- **명판 엠보싱**: 기존 좌측 "잇벤토리"/타이틀 구조는 그대로 두고, 프레임 상단 중앙에 아주 작은(`text-[9px] tracking-[0.2em]`) "EATVENTORY" 텍스트를 추가하고 `text-shadow`로 양각 느낌을 줍니다(1-5 참고). 정보 구조에 영향 없는 순수 장식.
- **손잡이 하이라이트**: 기존 세로 그라데이션(`from-[#C7CDD6] to-[#A7AFBC]`)에 중간 하이라이트 스톱을 추가해 원통형 금속처럼 보이게 합니다: `linear-gradient(90deg, #AEB6C2, #F0F2F5 45%, #AEB6C2 58%, #8C93A1)` — 방향이 `to-b`(세로)가 아니라 손잡이 폭 방향(가로, 즉 손잡이가 세워진 상태 기준 좌우) 그라데이션으로 바뀌는 점에 주의(원통 반사는 폭 방향으로 생김). 손잡이 자체에 `shadow-[0_3px_6px_rgba(0,0,0,0.25)]` 추가.
- 프레임 좌우 안쪽 가장자리에 아주 옅은 브러시드 메탈 스트립(선택 구현): `repeating-linear-gradient(180deg, rgba(255,255,255,.5) 0 1px, transparent 1px 3px)`를 4px 폭 pseudo-element로. 성능/복잡도 부담되면 생략 가능(필수 아님).
- 손잡이는 여전히 `<div aria-hidden="true">` 장식 요소.

### 3-2. 온도 다이얼 탭 (`TemperatureTabs`, 변경 없음)

v1 그대로 유지합니다. 기존 `TABS`/`tab`/`setTab` 로직, 활성/비활성 스타일 규칙 모두 동일.

### 3-3. 선반 섹션 (`ShelfSection`, 3D 두께감 + 재료 배치 컨테이너 교체)

- **선반 바(신규)**: 기존 `h-[6px] rounded-full` 단색 바를 "유리 선반 두께"로 교체합니다. 냉장/실온 구역은 `h-[9px] rounded-md`에 `linear-gradient(180deg, rgba(255,255,255,.95), var(--zone-border))` 배경 + `shadow-[0_3px_5px_-2px_rgba(20,40,70,0.25)]`(실온은 톤만 갈색 계열로 교체)로 "위는 빛나고 아래는 그림자 지는" 두께를 표현합니다. 냉동 구역은 기존처럼 `border-t-[2.5px] border-dashed`를 유지.
- **냉장 구역 조명 워시(신규)**: 냉장 선반 패널 최상단 36px 높이에 `radial-gradient(ellipse at 50% -10%, rgba(255,255,255,.85), transparent 70%)` 오버레이(`pointer-events-none`, `absolute inset-x-0 top-0`)를 추가해 "문을 열면 위에서 조명이 쏟아지는" 느낌을 줍니다.
- **냉동 구역 서리 결(신규)**: 기존 도트 패턴(`radial-gradient(#fff 1px, transparent 1px)`, 6px 간격, opacity 6~8%)에 더해 `repeating-linear-gradient(45deg, rgba(255,255,255,.25) 0 2px, transparent 2px 7px)`를 저opacity로 겹쳐 성에를 긁은 듯한 결을 추가합니다. 성능 이슈 시 스크래치 레이어만 생략 가능(도트 패턴은 v1부터 유지).
- **재료 배치 컨테이너 교체(핵심 변경)**: 기존 `<div className="grid grid-cols-3 gap-2 md:grid-cols-4 md:gap-3 lg:grid-cols-5">`를 아래로 교체합니다.
  ```
  <div className="flex flex-wrap items-end gap-x-3.5 gap-y-5 min-h-[78px] md:gap-x-4 md:gap-y-6 md:min-h-[86px]">
  ```
  `items-end`가 핵심입니다 — 폭/높이가 제각각인 용기들이 선반 "바닥선"에 정렬되어야 실물처럼 보입니다. `IngredientCard`(그리드 아이템)를 순회하며 렌더링하던 자리에 `IngredientVessel`을 순회 렌더링합니다. `Fridge.jsx`의 `grouped`/`group.items.map` 로직은 변경 없음 — 렌더링되는 자식 컴포넌트와 그 부모 컨테이너 클래스만 바뀝니다.
- 실온 섹션의 "도어 포켓" 처리(`border-t-4` 우드톤)는 v1과 동일 유지.

### 3-4. 재료 표현 — 카드 → 용기(Vessel) (핵심 변경, 신규: `IngredientVessel`)

`IngredientCard`를 대체하는 신규 컴포넌트입니다. **props와 클릭 인터랙션(`ingredient`, `onClick` → 수정 모달 오픈)은 기존과 100% 동일**하게 유지해 `Fridge.jsx`의 데이터 흐름을 그대로 재사용합니다. 바뀌는 것은 내부 마크업/스타일뿐입니다.

**구조 (바깥→안쪽)**

1. `vwrap` — 래퍼. `relative flex flex-col items-center w-14 md:w-16`, 개별 회전 적용(아래 참고). 클릭 가능한 루트는 이 래퍼 전체(`<button>`)입니다 — 탭 타깃이 실루엣보다 작아지지 않도록 `min-h-11`(44px) 이상 유지.
2. D-day 배지 — `vwrap` 우상단에 `absolute -top-2.5 -right-2`로 부착. 스타일/회전각/조건(`expiresInDays` 있을 때만)은 v1 3-5와 완전히 동일.
3. `shape` — 실루엣 본체. 아래 4장의 매핑표에 따라 클래스가 결정됩니다. 배경은 `linear-gradient(155deg, #fff, var(--zone-fill2) 75%)`(플라스틱/유리 용기의 옅은 광택), 테두리는 소속 구역의 팔레트 테두리색(1-2 표), 텍스트/아이콘 색은 구역 텍스트 포인트 컬러. 카테고리 텍스트 배지(실온/냉장/냉동)는 제거하지 않고 이름 아래 `text-[10px] opacity-70`로 유지(v1과 동일, 위계상 가장 약함).
4. `ground` — 접지 그림자. `shape` 바로 아래, `w-[70%] h-1.5 rounded-full` 배경 = 구역 테두리색, `opacity-45 blur-[1.5px]`. 큰 실루엣(`md` 사이즈)은 `w-[85%] h-[7px]`.
5. 재료명 — `ground` 아래, `text-[11px] font-medium text-gray-900 dark:text-gray-100 text-center`. **항상 실루엣 밖, 항상 가로 정렬**(회전 영향 받지 않도록 `vwrap` 안에서 회전은 `shape`+`ground`+이름 전체를 감싸는 값이지만, 회전각을 3deg 이내로 제한해 가독성 손실이 없게 합니다).

**아이콘**: 기존 `ICON_RULES`(계란→Egg, 우유→Milk, 채소→Leaf, 두부→Square, 밥→UtensilsCrossed, 식용유→Droplet, 그 외→Package) 매핑 로직은 그대로 재사용해 `shape` 중앙에 배치합니다. 실루엣이 이미 재료 종류를 암시하므로 아이콘은 보조 신호로 축소(기존과 동일하게 `size 16~18`).

**개별 회전(결정론적)**: `Math.random()` 금지 — 재렌더/재정렬 시 흔들리면 안 됩니다. `ingredient.id`를 시드로 고정 배열에서 선택합니다.
```js
const ROTATE_STEPS = [-3, 2, -2, 3, 0] // deg
const rotate = ROTATE_STEPS[ingredient.id % ROTATE_STEPS.length]
```
`vwrap`에 `style={{ transform: `rotate(${rotate}deg)` }}` 또는 대응하는 Tailwind arbitrary value 사용.

**hover/active**: 기존과 동일한 절제 원칙 — `hover:brightness-105 hover:-translate-y-0.5 active:scale-[0.97] transition`을 `shape`에 적용(래퍼 전체가 아니라 실루엣에만 적용해 이름 텍스트는 흔들리지 않게).

### 3-5. D-day 배지 (변경 없음)

v1 3-5와 완전히 동일. 위치 기준점만 "카드"에서 "용기 래퍼(`vwrap`)"로 바뀌었을 뿐 스타일/로직/색상은 동일합니다.

### 3-6. + 버튼 / 3-7. 레시피 추천받기 버튼 / 3-8. 검색 입력 (변경 없음)

v1 3-6~3-8과 완전히 동일. 재변경 없음.

## 4. 재료 실루엣(Vessel Shape) 매핑

`IngredientCard`의 기존 아이콘 키워드 매핑 로직(`ICON_RULES`)에 "실루엣 클래스"를 짝지어 확장합니다. 아이콘 매핑을 못 찾으면 `Package` 아이콘 + `box` 실루엣(기본값)으로 폴백하던 것과 동일한 원칙으로, 실루엣도 매칭 실패 시 `box`로 폴백합니다.

| 키워드 | 아이콘(기존) | 실루엣(신규) | 실루엣 설명 | 사이즈 |
|---|---|---|---|---|
| 계란 | `Egg` | `egg` | 위 모서리는 둥글고 아래는 각진 상자(에그박스 단순화) | sm |
| 우유 | `Milk` | `carton` | 오각형 지붕(우유팩) — `clip-path: polygon(12% 100%, 12% 30%, 50% 6%, 88% 30%, 88% 100%)` | md |
| 대파, 마늘, 양파 등 채소 | `Leaf` | `bundle` | 비대칭 라운드(뭉치/망 포장) — `border-radius: 46% 54% 52% 48% / 58% 54% 46% 42%` | sm~md |
| 두부 | `Square` | `box` | 각진 상자 + 대각선 광택 하이라이트(비닐 포장 반사) | md |
| 밥 | `UtensilsCrossed` | `dome` | 위가 둥근 돔형(밀폐용기 뚜껑) — `border-radius: 50% 50% 14% 14%` | sm |
| 만두, 냉동식품 | `Package` | `pouch` | 윗변이 지그재그(냉동 파우치 접힌 입구) — `clip-path` 지그재그 폴리곤 | sm~md |
| 식용유 | `Droplet` | `bottle` | 목이 좁은 병 실루엣 — `clip-path` 사다리꼴+목 폴리곤 | sm |
| 감자, 기타 | `Package` (기본값) | `box` (기본값) | 위와 동일한 각진 상자 | sm |

실루엣 클래스는 총 7개입니다(`egg`, `carton`, `bundle`, `box`, `dome`, `pouch`, `bottle`). 사이즈는 `sm`(44px 높이)/`md`(58px 높이) 2단계만 사용해 관리 복잡도를 제한합니다. 신규 실루엣 추가는 이번 스펙 범위 밖(필요 시 후속 스펙에서 다룸).

## 6. 반응형 규칙

- **모바일(~480px)**: 냉장고 프레임 전체 폭, 구역은 실온 → 냉장 → 냉동 세로 스크롤(변경 없음). 재료는 `flex-wrap` 자연 줄바꿈(그리드 열수 개념 자체가 사라짐 — 용기 폭이 제각각이므로 한 줄에 들어가는 개수가 자동으로 달라짐).
- **태블릿(768px~)**: 프레임 `max-w-[640px]` 중앙 정렬. `gap-x-4 gap-y-6`로 여백만 확대.
- **데스크톱(1024px~)**: 프레임 `max-w-[720px]`, 좌측 사이드 네비 병행(`docs/02` 공통 규칙). 용기 폭이 `w-14→w-16`로 소폭 확대.
- 하단 네비게이션의 모바일/데스크톱 전환 규칙은 냉장고 프레임과 독립적으로 동작 — 변경 없음.
- 다크모드: 6장(1-2, 1-5) 팔레트의 dark 값 사용. 냉장/냉동 구역은 다크에서도 프레임 배경보다 한 단계 밝게 유지(변경 없음). 신규 요소(개스킷, 명판, 조명 워시, 서리 스크래치)도 1-5의 dark 값을 반드시 적용해야 함 — 라이트 값만 넣고 누락하는 실수가 v1→v2 개정에서 가장 흔한 실수 지점.
