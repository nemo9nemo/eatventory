# 잇벤토리 (Eatventory) — 냉장고 화면 디자인 스펙

작성: 정하늘 (프로덕트 디자이너)
대상: `src/pages/Fridge.jsx`, `src/components/IngredientCard.jsx`를 재구현할 프론트엔드 엔지니어
기준: `docs/01_기획서.md`, `docs/02_와이어프레임_UI명세.md`의 정보 구조(전체/실온/냉장/냉동 탭, 재료 카드, D-day 배지, + 버튼, 레시피 추천받기 버튼)를 100% 유지하고 **시각 표현만** 재해석합니다. 기능/props/상태 로직은 변경하지 않습니다.

## 0. 디자인 컨셉

> 실물을 흉내내되, 정보는 실물보다 빨리 읽혀야 한다.

"냉장고 화면 = 카드 그리드"가 아니라 "**문을 연 냉장고 내부를 들여다보는 화면**"으로 재해석합니다.

- 화면 전체가 하나의 **냉장고 도어 프레임**(스테인리스 or 화이트 도어)으로 감싸지고, 그 안에 실온/냉장/냉동이 서로 다른 "온도 구역"으로 시각화됩니다.
- 탭(전체/실온/냉장/냉동)은 냉장고 앞면의 **온도 다이얼/조작부** 은유로, 선택된 구역에 조명이 켜진 것처럼 보입니다.
- 실온 재료는 냉장고 안이 아니라 **도어 포켓(문 안쪽 바구니, 우드톤)**, 냉장 재료는 **유리 선반 + 밝은 백색광**, 냉동 재료는 **성에 낀 유리 선반(서리/저온 질감)** 으로 구분합니다.
- 재료 카드는 선반 위에 놓인 **작은 밀폐용기/포장 라벨**처럼 표현하되, 정보(이름 + D-day)는 기존과 동일하게 즉시 읽히도록 절제합니다.
- 유통기한 임박 표시는 카드 자체를 바꾸지 않고, 냉장고 문에 붙이는 **자석 스티커(메모지)** 은유의 D-day 배지로 표현합니다. 살짝 비뚤어진 회전각으로 "누군가 붙여놓은" 느낌을 줍니다.
- + 버튼은 도어 포켓에 붙은 **자석 버튼**, "레시피 추천받기" 버튼은 문에 붙은 **메뉴 쪽지(핀으로 고정된 메모)** 로 표현합니다.

## 1. 색상 팔레트

Tailwind는 커스텀 팔레트 없이 arbitrary value(`bg-[#hex]`)로 표현합니다. 기존 브랜드 색(emerald-600)은 CTA(레시피 추천받기, 저장 버튼)에 계속 사용해 일관성을 유지합니다.

### 1-1. 프레임 / 외관

| 용도 | 라이트 | 다크 | Tailwind 예시 |
|---|---|---|---|
| 도어 프레임 배경 | `#F3F4F6` | `#20242B` | `bg-[#F3F4F6] dark:bg-[#20242B]` |
| 프레임 테두리 | `#E2E4E9` | `#333944` | `border-[#E2E4E9] dark:border-[#333944]` |
| 손잡이(핸들) | `#C7CDD6` → `#A7AFBC` (세로 그라데이션) | `#5B6270` → `#454B57` | `bg-gradient-to-b from-[#C7CDD6] to-[#A7AFBC]` |
| 상단 명판 텍스트 | `#6B7280` | `#9AA1AC` | `text-gray-500 dark:text-gray-400` |

### 1-2. 온도 구역별 배경 (탭/선반 공통)

| 구역 | 배경(라이트) | 배경(다크) | 테두리/포인트 | 텍스트 포인트 |
|---|---|---|---|---|
| 실온 (도어 포켓, 우드톤) | `linear-gradient(#F1E6D2, #E8DAC0)` | `linear-gradient(#3A3226, #2E281F)` | `#D9C9A3` | `#8A6D3B` / dark `#D4B87A` |
| 냉장 (유리 선반, 백색광) | `linear-gradient(#F7FBFF, #E9F2FC)` | `linear-gradient(#1B2A3D, #16222F)` | `#BFDCF7` | `#1D5A96` / dark `#8FC2F2` |

- 냉동 구역 배경 위에 `background-image: radial-gradient(#fff 1px, transparent 1px)` 4~6px 간격의 아주 옅은(투명도 6~8%) 도트 패턴을 얹어 서리 입자를 표현합니다(선택 사항, 성능 이슈 시 생략 가능).

## 3. 컴포넌트별 스타일 규칙

### 3-1. 냉장고 프레임 (신규: `FridgeFrame`)

- 화면 최상단을 감싸는 컨테이너. `Layout`이 아니라 `Fridge.jsx` 내부에서만 사용.
- 배경 `#F3F4F6`(라이트)/`#20242B`(다크), `border`, `rounded-[28px]`, `shadow-[0_1px_0_rgba(255,255,255,0.6)_inset]`로 도어 패널의 미세한 하이라이트 표현.
- 내부 상단에 얇은 "명판" 영역: 좌측 "잇벤토리" 라벨(11px, muted) + "냉장고" 타이틀(기존 `text-lg font-medium` 유지), 우측에 검색 아이콘 + 손잡이 바.
- 손잡이는 `<div>` 장식 요소(비인터랙션), `aria-hidden="true"`.

### 3-2. 온도 다이얼 탭 (기존 세그먼트 탭 대체: `TemperatureTabs`)

- 기존 `TABS` 배열/상태 로직(`tab`, `setTab`) 그대로 재사용. 스타일만 교체.
- 컨테이너: `rounded-full bg-black/5 dark:bg-white/5 p-1 flex gap-1`.
- 비활성 버튼: 투명 배경, `text-gray-500`.
- 활성 버튼: 선택된 구역의 팔레트(1-2 표 참조)를 조명처럼 채움 — 실온=우드톤, 냉장=백색광 블루, 냉동=아이시 퍼플, 전체=`bg-white dark:bg-gray-800` 중립.
- 활성 버튼에는 `shadow-sm` + 살짝 밝은 텍스트 색(팔레트의 텍스트 포인트 컬러)을 적용해 "불이 켜진" 느낌을 줌.
- 전환 애니메이션: `transition-colors duration-200`만 사용(과한 모션 지양).

### 3-3. 선반 섹션 (신규: `ShelfSection`, 기존 그룹 렌더링부 대체)

- 각 구역(`room`/`fridge`/`frozen`) 최상단에 "선반 바" — `h-[6px] rounded-full` 그라데이션(팔레트의 테두리색), 냉동 구역은 `border-dashed border-t-2` 방식으로 대체 가능.
- 선반 바 위/아래로 살짝 배경 톤이 스며드는 `rounded-2xl` 패널로 해당 구역 전체를 감싸 "선반 칸" 하나처럼 보이게 함 (padding `p-3`).
- 섹션 라벨은 기존처럼 "냉장 선반 · 5개" 텍스트 유지, 팔레트의 텍스트 포인트 컬러 사용.
- 실온 섹션만 패널 상단에 `rounded-t-2xl` 대신 도어 포켓처럼 **위가 잘린 바구니 형태**(`clip-path` 없이 상단 테두리를 두껍게 `border-t-4` 처리)로 구분해 "문 안쪽"이라는 위치 차이를 암시.

### 3-4. 재료 카드 (`IngredientCard` 재작업)

- 기존 props(`ingredient`, `onClick`)와 클릭 인터랙션(수정 모달 오픈) 그대로 유지.
- 카드 배경/테두리는 소속 구역의 팔레트(1-2 표)를 따름 — 즉 `Fridge.jsx`에서 `category`를 카드에 내려주는 기존 방식 그대로, `IngredientCard` 내부에서 `CATEGORY_STYLE` 맵만 새 팔레트로 교체.
- 카드는 밀폐용기 라벨처럼 `rounded-2xl`, 내부 상단에 재료 아이콘(lucide-react 아이콘 1개, 카테고리별 대표 아이콘 매핑 — 예: 기본 `Package`, 유제품 `Milk`, 채소 `Leaf` 등. 아이콘 매핑 테이블은 4장 참고) + 하단에 재료명.
- 기존의 카테고리 텍스트 배지(`실온`/`냉장`/`냉동` 라벨)는 제거하지 않되, 카드 하단 재료명 아래 작은 pill로 유지(선반 자체가 구역을 이미 표현하므로 시각적 비중은 낮춤 — `text-[10px] opacity-70`).
- hover/active: `hover:brightness-105 active:scale-[0.97] transition`.

### 3-5. D-day 배지

- 카드 우상단 바깥으로 살짝 튀어나오는 위치(`absolute -top-2 -right-1.5`), `transform: rotate(...)`로 스티커처럼 붙인 느낌(1-3 표의 회전각).
- `urgent`(D-2 이하)/`soon`(D-3~5)/정상 3단계는 기존 `IngredientCard`의 `urgent`/`soon` 계산 로직을 그대로 사용하고 클래스만 교체.

### 3-6. + 버튼 (자석 버튼)

- 기존 `fixed bottom-20 right-5` 방식 대신, **냉장고 프레임 내부** 우하단에 `absolute`로 배치(프레임이 `relative`가 되어야 함) — "진짜 문에 붙은 자석"처럼 보이도록 화면 바깥이 아니라 프레임 안쪽에 위치.
- 모바일에서 프레임 하단 CTA와 겹치지 않도록 `bottom-20`(CTA 위), 데스크톱은 `md:bottom-6`.
- 스타일: `rounded-full bg-emerald-600 text-white shadow-md`, 살짝 입체감을 위해 `ring-2 ring-white/40 dark:ring-black/20` inset 느낌 추가.

### 3-7. 레시피 추천받기 버튼 (메모 쪽지)

- 기존 위치/조건(`ingredients.length > 0`일 때만 노출) 유지.
- 스타일: 흰 배경 카드에 상단 중앙 `Pin`(lucide) 아이콘을 `-top-2` 위치에 살짝 회전(`-rotate-12`)시켜 "핀으로 고정한 메모지" 느낌.
- 텍스트/색은 기존과 동일(`text-emerald-600 font-medium`).

### 3-8. 검색 입력 / 헤더

- 검색 입력은 기존 로직 유지, 프레임 명판 영역 톤에 맞춰 `bg-white/70 dark:bg-black/20 backdrop-blur-0`(블러 없이 반투명만) 정도로 톤 조정.
- 별도 구조 변경 없음.

## 4. 재료 아이콘 매핑 (선택 구현)

카드에 아이콘을 넣을 경우 `lucide-react` 기준 매핑 예시(재료명 키워드 매칭, 못 찾으면 기본 `Package`):

| 키워드 | 아이콘 |
|---|---|
| 계란 | `Egg` |
| 우유 | `Milk` |
| 대파, 마늘, 양파 등 채소 | `Leaf` |
| 두부 | `Square` |
| 밥 | `UtensilsCrossed` |
| 만두, 냉동식품 | `Package` |
| 식용유 | `Droplet` |
| 감자, 기타 | `Package` (기본값) |

아이콘 매핑이 부담스러우면 생략하고 텍스트 카드만 유지해도 무방(정보 전달 우선, 장식은 선택).

## 6. 반응형 규칙

- **모바일(~480px)**: 냉장고 프레임이 화면 폭 전체를 채우는 세로형 도어 1장으로 표현. 구역은 위에서 아래로 실온 → 냉장 → 냉동 순서로 세로 스크롤(문을 위에서 아래로 훑는 느낌). 카드 그리드 3열.
- **태블릿(768px~)**: 프레임 `max-w-[640px]` 중앙 정렬, 카드 그리드 4열.
- **데스크톱(1024px~)**: 프레임 `max-w-[720px]`, 좌측 사이드 네비게이션과 나란히 배치(`docs/02` 공통 규칙 준수). 카드 그리드 5열까지 허용.
- 하단 네비게이션은 모바일 하단 고정 → 데스크톱 좌측 사이드바 전환이라는 기존 규칙(`BottomNav`)을 그대로 따르며, 냉장고 프레임 자체의 반응형과는 독립적으로 동작.
- 다크모드: 6장 팔레트의 dark 값 사용. 냉장/냉동 구역은 다크에서도 "조명이 켜진" 대비를 유지하기 위해 명도를 프레임 배경보다 한 단계 밝게 유지(냉장고 문을 열면 내부가 밝다는 은유 보존).

## 7. 기존 컴포넌트와의 관계

| 컴포넌트 | 처리 방식 |
|---|---|
| `IngredientCard` | 유지 + 재스타일링(팔레트/아이콘/배지 회전만 변경, props·클릭 핸들러 불변) |
| `EmptyState` | 그대로 재사용(색상 wrapper만 선반 팔레트로 감쌈) |
| 세그먼트 탭(현재 `Fridge.jsx` 인라인 구현) | `TemperatureTabs`라는 이름으로 분리 권장(선택), 로직은 기존 `TABS`/`tab`/`setTab` 그대로 |
| `AddIngredientModal` | 이번 스펙 범위 밖(변경 없음). 단, 모달 내 세그먼트 버튼(실온/냉장/냉동 선택)도 톤을 맞추고 싶다면 1-2 팔레트를 동일 적용 가능(선택 사항, 필수 아님) |
| 신규 컴포넌트 제안 | `FridgeFrame`(프레임 래퍼), `ShelfSection`(구역별 선반 패널) 2개 신규 컴포넌트로 분리하는 것을 권장. 둘 다 순수 프레젠테이션 컴포넌트(상태 없음)로 만들면 `Fridge.jsx`의 기존 데이터 흐름(`useApp`, `filtered`, `grouped`)을 그대로 재사용 가능 |

## 8. 구현 범위 밖

- 실제 성에 텍스처 이미지, 금속 반사 이미지 등 래스터 에셋은 사용하지 않습니다(순수 CSS로만 표현). 필요 시 아주 옅은 CSS 그라데이션/도트 패턴만 허용.
- 문 여닫는 애니메이션, 조명 점멸 등 과도한 모션은 범위 밖입니다(정보 인지 속도를 해치지 않는 절제 원칙).
