# 잇벤토리 (Eatventory) — 화면 와이어프레임 & UI 명세

1단계 기획서의 핵심 기능(P0: 재료 저장소, 레시피 추천, 레시피 상세 / P1 일부: 검색, 유통기한 표시, 즐겨찾기)을 기준으로 화면을 구성합니다.

## 1. 화면 목록 및 흐름

**하단 네비게이션 (3탭, 모바일/데스크톱 공통 레이아웃 골격)**
- 홈
- 냉장고 (재료 저장소)
- 즐겨찾기

**화면 목록 (총 6개)**

| # | 화면명 | 진입 경로 | 우선순위 |
|---|---|---|---|
| 1 | 홈 | 앱 진입 시 기본 화면 | P0 |
| 2 | 냉장고 (재료 저장소) | 하단 네비게이션 | P0 |
| 3 | 재료 추가/수정 (모달) | 냉장고 화면의 "+" 버튼 | P0 |
| 4 | 레시피 추천 리스트 | 홈 또는 냉장고의 "레시피 추천받기" | P0 |
| 5 | 레시피 상세 | 레시피 카드 클릭 | P0 |
| 6 | 즐겨찾기 | 하단 네비게이션 | P1 |

**화면 흐름**

```
홈 ──(레시피 추천받기)──▶ 레시피 추천 리스트 ──(카드 클릭)──▶ 레시피 상세
 │                                                              ▲
 └─(하단 네비)─▶ 냉장고 ──(+ 재료 추가)──▶ 재료 추가/수정 모달   │
                  │                                              │
                  └──(레시피 추천받기)──▶ 레시피 추천 리스트 ─────┘

하단 네비 ──▶ 즐겨찾기 ──(카드 클릭)──▶ 레시피 상세
```

## 2. 화면별 명세

### 화면 1. 홈

- **목적**: 앱 진입 시 현재 재료 현황을 요약하고, 바로 레시피 추천으로 이어주는 진입점 역할
- **레이아웃 구성 (상단 → 하단)**
  1. 헤더: 서비스 로고/이름, 검색 아이콘
  2. 재료 요약 카드: "보유 재료 N개 / 유통기한 임박 M개" + "냉장고 보기" 링크
  3. "오늘 만들 수 있는 요리" 섹션: 추천 레시피 카드 가로 스크롤 (3~4개 미리보기)
  4. "레시피 더 보기" 버튼 → 레시피 추천 리스트로 이동
  5. 하단 네비게이션 바

| 요소 | 설명 | 인터랙션 |
|---|---|---|
| 재료 요약 카드 | 실온/냉장/냉동 합산 재료 개수, 유통기한 임박 개수 | 클릭 시 냉장고 화면으로 이동 |
| 추천 레시피 카드 | 레시피 썸네일, 이름, "재료 N/M개 보유" 배지 | 클릭 시 레시피 상세로 이동 |
| 레시피 더 보기 버튼 | 전체 추천 리스트로 이동 | 클릭 시 레시피 추천 리스트 화면 이동 |

- **상태**: 등록된 재료가 0개일 때 → 추천 섹션 대신 "재료를 먼저 등록해보세요" 안내 + 냉장고 이동 버튼

### 화면 2. 냉장고 (재료 저장소)

- **목적**: 보유 재료를 실온/냉장/냉동으로 구분해 등록·조회·삭제하는 핵심 화면. 냉장고+선반 UI로 시각화
- **레이아웃 구성 (상단 → 하단)**
  1. 헤더: "냉장고" 타이틀, 검색 아이콘
  2. 구분 탭: 전체 / 실온 / 냉장 / 냉동
  3. 선반 영역: 탭에 해당하는 재료를 선반(가로 구분선) 단위 카드 그리드로 표시, 유통기한 임박 재료는 배지로 강조
  4. 재료 카드: 아이콘, 이름, D-day(있는 경우)
  5. 플로팅 "+" 버튼 (재료 추가)
  6. 하단 네비게이션 바
  7. "이 재료로 레시피 추천받기" 버튼 (재료 1개 이상일 때 노출)

| 요소 | 설명 | 인터랙션 |
|---|---|---|
| 구분 탭 | 전체/실온/냉장/냉동 필터 | 탭 클릭 시 해당 카테고리만 표시 |
| 재료 카드 | 재료명 + D-day 배지(임박 시 경고색) | 클릭 시 수정 모달, 길게 누르면 삭제 확인 |
| + 버튼 | 재료 추가 모달 오픈 | 클릭 시 화면 3으로 이동 |
| 레시피 추천받기 버튼 | 현재 보유 재료 기준 추천 리스트 이동 | 클릭 시 화면 4로 이동 |

- **상태**:
  - 빈 상태(해당 카테고리 재료 0개): "아직 등록된 재료가 없어요" + 추가 버튼 강조
  - 유통기한 3일 이내: 카드에 경고색(D-day 배지) 표시

### 화면 3. 재료 추가/수정 (모달)

- **목적**: 재료명, 보관 구분(실온/냉장/냉동), 유통기한(선택)을 입력해 등록
- **레이아웃 구성 (상단 → 하단)**
  1. 모달 헤더: "재료 추가" 타이틀, 닫기(X) 버튼
  2. 재료명 입력 필드
  3. 보관 구분 선택 (실온/냉장/냉동 — 세그먼트 버튼)
  4. 유통기한 입력 (선택, 날짜 피커)
  5. 저장 버튼 (하단 고정)

| 요소 | 설명 | 인터랙션 |
|---|---|---|
| 재료명 입력 | 텍스트 입력, 자동완성(선택) | 입력값 없으면 저장 비활성 |
| 보관 구분 세그먼트 | 실온/냉장/냉동 중 1개 선택 | 기본값: 냉장 |
| 유통기한 입력 | 날짜 선택, 미입력 가능 | 미입력 시 D-day 배지 없음 |
| 저장 버튼 | 재료 목록에 반영 후 모달 닫기 | 필수값(재료명) 미입력 시 인라인 에러 표시 |

- **상태**: 수정 모드 진입 시 기존 값이 채워진 상태로 오픈, 하단에 "삭제" 텍스트 버튼 추가 노출

### 화면 4. 레시피 추천 리스트

- **목적**: 보유 재료 기준으로 만들 수 있는 레시피를 매칭도 순으로 제시
- **레이아웃 구성 (상단 → 하단)**
  1. 헤더: "레시피 추천" 타이틀, 뒤로가기
  2. 필터 chip: 전체 / 바로 만들 수 있어요(재료 100% 보유) / 조금만 더 있으면 돼요
  3. 레시피 카드 리스트(세로): 썸네일, 이름, 보유 재료 비율, 부족한 재료 태그
  4. 무한 스크롤 또는 더 보기

| 요소 | 설명 | 인터랙션 |
|---|---|---|
| 필터 chip | 매칭 조건별 리스트 필터링 | 클릭 시 리스트 즉시 갱신 |
| 레시피 카드 | 이름, "재료 4/5개 보유" 배지, 부족 재료 태그(예: "대파 없음") | 클릭 시 레시피 상세로 이동 |
| 즐겨찾기 아이콘 | 카드 우측 상단 별 아이콘 | 클릭 시 즐겨찾기 토글 |

- **상태**: 매칭되는 레시피가 없을 때 → "조건에 맞는 레시피가 없어요, 재료를 더 등록해보세요" 안내

### 화면 5. 레시피 상세

- **목적**: 선택한 레시피의 재료 목록과 조리 순서를 확인하고 그대로 따라 만들 수 있게 안내
- **레이아웃 구성 (상단 → 하단)**
  1. 헤더: 뒤로가기, 즐겨찾기 토글
  2. 대표 이미지, 레시피명, 조리 시간/난이도
  3. 재료 목록: 보유 재료(체크 표시) vs 부족한 재료 구분 표시
  4. 조리 순서: 번호가 매겨진 단계별 카드(텍스트 + 선택적 이미지)

| 요소 | 설명 | 인터랙션 |
|---|---|---|
| 재료 목록 | 보유 여부 아이콘 구분(체크/느낌표) | 없음 (읽기 전용) |
| 조리 순서 카드 | 단계 번호 + 설명 | 없음, 스크롤로 탐색 |
| 즐겨찾기 토글 | 별 아이콘 | 클릭 시 즐겨찾기 추가/해제, 즐겨찾기 화면에 반영 |

- **상태**: 없음 (정적 콘텐츠 위주)

### 화면 6. 즐겨찾기

- **목적**: 저장해둔 레시피를 모아보는 화면
- **레이아웃 구성**: 헤더 "즐겨찾기" + 레시피 카드 리스트(화면 4와 동일한 카드 컴포넌트 재사용) + 하단 네비게이션
- **상태**: 빈 상태 → "즐겨찾기한 레시피가 없어요" + 레시피 추천 리스트로 이동하는 버튼

## 3. 공통 UI 규칙

- **톤앤매너**: 따뜻하고 정돈된 느낌. 재료 신선도/보관 구분을 색으로 구분하되 과도한 색 사용은 지양
  - 실온: 중립(회색 계열) / 냉장: 파랑 계열 / 냉동: 하늘색~보라 계열
  - 유통기한 임박: 경고색(주황/빨강), 정상: 기본 텍스트 색
- **재사용 컴포넌트**
  - 재료 카드 (냉장고 화면, 재료 추가 모달에서 공통 스타일)
  - 레시피 카드 (홈 미리보기, 추천 리스트, 즐겨찾기에서 동일 컴포넌트 재사용)
  - 하단 네비게이션 바 (홈/냉장고/즐겨찾기 3탭, 모바일 하단 고정, 데스크톱에서는 좌측 사이드바로 전환 가능)
  - 세그먼트 버튼 (실온/냉장/냉동 선택 — 재료 추가 모달, 냉장고 필터 탭에서 공통 사용)
  - 빈 상태 컴포넌트 (아이콘 + 안내문구 + CTA 버튼, 화면 2/4/6 공통)
- **반응형 원칙**
  - 모바일(~480px): 하단 네비게이션, 리스트/카드 1열
  - 태블릿/데스크톱: 좌측 사이드 네비게이션으로 전환, 재료/레시피 카드 2~3열 그리드
